# overview
A proxy for browsing the modern web on older devices from the 2000s or game consoles with built-in browsers.

Although it's called Wii, it can be used on any device other than the Wii.
We have tested it on a certain number of devices.
The default port is 8000, but you can change it to your preference.


## Requirements
All you need is a PC or server capable of running Python 3.
It's easier to use a fixed IP address.

## How to use
Download Server.py from WiiProxy and run it via command line or directly.

Then, enter the IP address and port number in the terminal's URL field, followed by the website URL.
Alternatively, if your device allows proxy settings, you can pre-enter the IP address and port.
